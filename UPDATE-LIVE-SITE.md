# Vowly Stage 8.2 — sidebar polish

This update cleans up the navigation and sidebar layout.

Changes:
- Removed all sidebar symbols/icons.
- Centred and tidied the bottom information/plan card.
- Prevented the bottom card from looking cramped on shorter screens.
- Removed the obsolete duplicate Seating Plan placeholder from Dashboard.
- Avatar initials now update automatically from the current couple names.

Deploy:
1. Upload all Stage 8.2 files to your existing `ajlubassa/vowly` GitHub repository.
2. Replace the existing files.
3. Commit:
   `Vowly Stage 8.2 sidebar polish`
4. Keep Railway `web-volume` mounted at `/data`.
5. Wait for Railway to show Online.
6. Open Vowly and press Ctrl + F5 once.
